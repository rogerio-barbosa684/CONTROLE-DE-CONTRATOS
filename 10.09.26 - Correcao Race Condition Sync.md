# 10/09/2026 - Correção de Race Condition no Sync Inicial

## Problema
A máquina 1 mostrava zero dados, mesmo com registros no Supabase. A máquina 2 mostrava tudo (foi onde os dados foram criados).

## Causa Raiz
**Race condition** no fluxo de login:

```
mostrarApp() chama:
  1. loadDataFromDB()          ← carrega IndexedDB (vazio na máquina 1)
     ├── loadFromServer()      ← fetch GET /api/sync (ASYNC, sem esperar)
     └── setTimeout(syncToServer, 2000)  ← dispara após 2s independentemente
  2. setTimeout(syncRealtime, 2000)  ← OUTRO ciclo de sync paralelo
```

### O que acontecia:
- `loadFromServer()` fazia GET ao servidor (async)
- 2 segundos depois, `syncToServer()` disparava **sem esperar** o GET terminar
- Enviava arrays vazios (`cachedContratos = []`) ao servidor → não deletava nada, mas não sincronizava
- Ao mesmo tempo, `syncRealtime()` disparava OUTRO ciclo de loadFromServer + syncToServer
- Resultado: 2 ciclos de sync concorrentes, nenhum completava corretamente

## Correções Aplicadas

### 1. `loadDataFromDB()` (linha ~2453)
```javascript
// ANTES (bug):
loadFromServer();
setTimeout(() => { syncToServer(); }, 2000);

// DEPOIS (corrigido):
loadFromServer().then(() => syncToServer()).catch(e => console.error('[SYNC] Erro no sync inicial:', e));
```
Agora `syncToServer()` só dispara **depois** que `loadFromServer()` completou e os dados foram mesclados no cache.

### 2. `mostrarApp()` (linha ~2234)
```javascript
// ANTES (bug):
loadDataFromDB();
setTimeout(() => { syncRealtime(); }, 2000);

// DEPOIS (corrigido):
loadDataFromDB();
```
Removido o `syncRealtime()` duplicado. O sync inicial já é feito dentro de `loadDataFromDB()`. O `syncRealtime()` periódico (a cada 30s) continua funcionando normalmente.

## Fluxo Corrigido
```
Login → mostrarApp() → loadDataFromDB()
  → carrega IndexedDB (pode estar vazio)
  → loadFromServer() [espera GET /api/sync completar]
  → syncToServer() [envia dados ao servidor SOMENTE após load completar]
  → syncRealtime() roda a cada 30s para manter atualizado
```

## Para Testar
1. Abrir Console (F12) na máquina 1
2. Fazer login
3. Verificar logs:
   - `[SYNC-GET] Recebidos: X contratos` → loadFromServer funcionou
   - `[SYNC-POST] Enviando TODOS: X registros` → syncToServer funcionou
   - `[SYNC-POST] Resposta: X` → servidor processou
4. Se aparecer `[SYNC] loadFromServer falhou:` → problema de rede/CSP/timeout
