Sincronizacao Multi-Dispositivo

Sistema robusto que garante dados consistentes entre multiplos computadores e usuarios simultaneos.

Como funciona

1. Dados Locais
Cada navegador mantem copia local dos dados em IndexedDB
2. GET Full Sync
A cada 30s, recebe TODOS os dados atualizados do servidor
3. POST Full Sync
Envia TODOS os registros locais ao servidor
4. Deduplicacao
Servidor compara timestamps e mantem a versao mais recente

Garantias

+
Todos os dados sempre enviados ao servidor
+
Deduplicacao automatica por timestamp
+
Soft delete - dados nunca sao perdidos
+
Retry automatico a cada 10s quando sync falha
+
Indicador visual de estado da sincronizacao

Seguranca e Controle de Acesso

Autenticacao e Autorizacao

*
JWT - Token de sessao via cookie HttpOnly (8h de validade)
*
CSRF - Token em todas as requisicoes de escrita
*
RBAC - 3 niveis: Admin, Setor Admin, Usuario
*
Empresas - Usuarios veem apenas dados de suas empresas
*
Setores - Restricao por setor organizacional

Protecoes Extras

*
Senhas - PBKDF2-SHA256 com 310.000 iteracoes
*
Rate Limiting - Max 10 tentativas/min no login
*
Audit Log - Registro completo de acoes dos usuarios
*
SMTP - Senha de e-mail criptografada com AES-256
*
Soft Delete - Exclusao logica, dados preservados
